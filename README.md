# Navega Seguro

Site do guia prático **Navega Seguro**, de prevenção a golpes digitais para pessoas idosas, familiares, educadores e desenvolvedores. O guia é produto do TCC de Brenoly Porto (Engenharia de Software, UPE Campus Garanhuns, 2026).

- HTML, CSS e JavaScript puros, sem dependências.
- Recursos: ajuste do tamanho da letra, alto contraste, versão para impressão e quiz "Mito ou Verdade?".
- O conteúdo vem do arquivo `08_Guia_base.md` (pasta Produzido do TCC).

## Publicar no GitHub Pages

1. Crie um repositório público (por exemplo, `navega-seguro`) e envie o conteúdo desta pasta para a branch `main`.
2. Em **Settings → Pages**, escolha **Deploy from a branch**, branch `main`, pasta `/ (root)`.
3. O site fica disponível em `https://<seu-usuario>.github.io/navega-seguro/`.

Para usar um domínio próprio depois, configure-o em **Settings → Pages → Custom domain**.
